# 详情审核与视觉增强：v2 范围修订

原 [v2 方案](../superpowers/specs/2026-09-23-system-blueprint-v2-design.md) 将文档设为只读，将连线修改、撤销/重做和流向动画留在首版之外。随后用户明确提出：生成图可能有误，阅读者应能在详情板审核、修改参数并立即反馈到流程图；同时增加有节制的配色和动态流向。本修订只扩展现有离线阅读器，不引入账号、在线协作或拖拽式图形编辑器。

## 审核路径

1. 打开自包含 HTML，点击已有节点、连接或分组，在详情板查看说明、关系、证据状态与来源。
2. 进入“编辑详情”，修改已有对象字段。节点支持名称、摘要、说明、类型、所属分组、信息依据、来源；连接支持两端、条件/标签、说明、类型、方向、信息依据、来源；分组支持名称、说明、父分组。对象 ID 保持稳定。
3. 保存前以 JSON Schema/Ajv 和语义规则校验整份图数据，成功后重新测量文字、投影、布局和渲染。失败时显示字段诊断，保留最近一次已接受的图；旧异步布局不能覆盖新版本。
4. 审核者可撤销/重做本次页面中的已接受修改，再下载修订 `.diagram.json` 与单文件 HTML。未保存的表单草稿会阻止下载，防止误以为已进入产物。`file://` 页面不写回原文件；关闭页面前未下载的修改不会持久保存。浏览器 SVG 使用当前已接受的数据；CLI 位图导出使用下载的修订 HTML。

详情板是已有对象的结构化属性编辑器。添加/删除节点或边、改 ID、任意拖拽布局及修改真实系统代码仍需在图数据或项目源码中另行完成。文案或证据状态由人工改为“已证实”并不自动构成事实，应根据来源核对。

来源字段每行一个路径；精确行号或特殊字符可写成 `"src/a.ts"#L12`。未改来源时保留原始数组与路径，不因编辑其他字段而重新解释来源文本。

## 视觉与动态边界

浅色主题继续保持工程图的中性背景，节点用低饱和处理蓝、判断琥珀、存储紫、外部青绿、起止绿作语义提示；关系用方向、文字和线型共同表达，异常红色不单独承担含义。深色主题使用相同语义映射。

仅主路径的有向连线可显示缓慢流向，提供暂停/播放开关，并遵守系统“减少动态效果”偏好。动效用于引导阅读，不是运行数据；静态 SVG、PNG、JPEG 始终全展开、无选中态、无动画。

## 本轮验收重点

- 点击详情、修改节点中文长文本、连接条件/两端/方向或分组字段后，画布和详情与已接受数据一致，文字无溢出。
- 判断出口条件重复、引用不存在或方向不合法时，出现可理解诊断，原图与下载数据保持不变。
- 连续编辑、撤销/重做、折叠与快速操作不会让旧布局覆盖新模型；分组内原始边映射仍完整。
- 下载修订 HTML 后在断网 `file://` 重新打开，修改仍在且不请求外部资源；禁用脚本摘要也反映修订内容。
- 桌面与窄屏详情不遮住正在审核的对象；播放/暂停及减少动态效果实际生效；独立静态 SVG 和位图包含完整已修订图形，且没有动画。

通过与否及浏览器、机器、截图和导出实测应写入当次验证报告；这里记录行为目标和相对原方案的范围变化。
