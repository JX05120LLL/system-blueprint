# 视觉、阅读与交付检查

## 默认视觉

浅色工程风为默认，深灰蓝主题可切换。背景、节点和边界保持低饱和；处理蓝、判断琥珀、存储紫、外部青绿、起止绿用于节点描边和浅填充。普通流程、数据和依赖连接按来源节点使用有限的高对比色板，同一来源保持同色；异常红和反馈琥珀保留语义色。主路径、选中与焦点仍须清楚，异常同时标文字，反馈用长虚线，依赖用短虚线。色板在大型图中可能复用，因此颜色必须与形状、箭头、标签和线型共同表达含义；普通节点不铺大块彩色容器。

100% 比例下标题 15 px、summary 13 px、条件标签 12 px。使用本机 Segoe UI / Microsoft YaHei / Noto Sans CJK SC 等系统字体，不加载网络字体。不同系统字形可能不同，确定像素交付用 PNG/JPEG。

内容先测量再布局；process 用矩形、decision 用菱形、start/end 用胶囊、store 用存储轮廓，external 有外部标记。分组只表达实际边界，最多两层；组标题和折叠控件保留空间。关键条件可直接读出，完整实现说明放详情。

## 方向与连线的选择

先按图的阅读任务选择主方向。多分支、跨组连接或长调用链的复杂图先试 RIGHT，让读者从左到右追踪主链；主路径短、层级少的流程可先试 DOWN。方向不按节点数或图类型机械决定。实际生成后同时看静态全图和桌面/窄屏交互视角；用于 README 时再看页面中的缩略图。比较主路径是否反复折返、跨组线是否绕行、标签是否压线，以及适应画布后的文字是否仍可辨认。阅读器底栏可切换横向/纵向，并下载保存所选方向；README 所用静态图仍按源模型默认方向生成。两者都拥挤时拆成总览与子图，保留完整数据与关系。

读图时，连接应呈现明确的直线或连续、平滑的弧线，避免一串短斜段与小圆角组成的类折线；允许回路和跨组连接必要的绕行，但不应穿过非端点节点、组标题或文字。箭头保持实际 source → target 的方向，静态图与交互图采用相同路径。检查相邻同色连接能否借助标签、端点、箭头和线型区分；颜色不足以辨认时需调整图的层次、方向或配色。圆弧不能代替内容分层，跨组长线过多时先精简模型或拆图。

## 阅读行为

- 支持拖动平移、滚轮/触控缩放、缩放按钮、适应画布与重置；普通缩放为 25%–300%。
- 长图首次打开若全图比例过小，采用 80% 起始视角，提示拖动阅读。用户选择适应画布或重置可显示全图，允许低于 25%，并提示放大看文字；继续放大保持连续。
- 点击或 Enter 查看节点、分组和边详情。Tab 遍历，Escape 关闭详情并返回焦点；分组控件支持 Enter/Space。边详情列原始关系，不提供含义不明的上下游按钮。
- 详情板可进入编辑表单，审核节点、连接或分组的已有字段。保存先校验整个模型，再重新测量和布局；无效修改显示诊断，不替换已接受的图。撤销/重做只作用于本次打开的页面，持久保存需要下载修订 JSON 和单文件 HTML。
- 上下游在原图遍历，循环不重复；折叠后投影到可见对象。高亮只是阅读辅助，不代表实时流量或运行状态。
- 主路径上的有向连线可显示缓慢流向，并有暂停/播放控件。系统偏好减少动态效果时默认静止；动效不代表真实运行。静态导出没有流向动画。
- 分组折叠摘要必须显示隐藏判断/条件提示，组详情保留全部隐藏流程条件。父组展开恢复子组状态。
- 重置关闭详情、清除高亮、恢复文档初始折叠并适应画布，保留当前主题。打开详情不会自动重置视角；拖动不应误选节点。

## 交付前实际检查

1. 先运行 validate，再 generate。打开生成的 HTML，等待 `window.blueprint.ready`；后续操作等待 `whenIdle()`，不能用固定延时替代就绪状态。
2. 在 1366×768、1920×1080 与 375×812 检查。页面以画布为主，窄屏工具栏不能横向溢出，详情可关闭。
3. 用实际 SVG 字体与几何核对：节点不重叠，文字在形状内，子节点在组内，连线不穿过非端点节点，条件不被节点遮挡，箭头在形状边界结束。再看整图截图中的主路径、交叉、短折段和相邻连线颜色；复杂图检查横向候选是否比纵向更易读。
4. 打开节点/边详情，检查假设与来源；修改中文长文本、判断条件、连接端点与方向，确认有效修改反映在画布，无效修改保留原图，并测试撤销/重做。再测试上下游、回路、两层折叠和快速连续操作。打开详情时核对选中对象仍可见；不能只留初始截图就宣称交互通过。
5. 下载修订 JSON 与 HTML；断网经 file:// 重新打开修订 HTML，确认改动仍在、没有外部请求。禁用 JS 只显示模型摘要；需要无脚本完整图时交付独立 SVG。
6. 暂停/播放流向并检查减少动态效果偏好。导出后独立打开 SVG，检查标题、条件、箭头、背景和完整边界且没有动画；检查 PNG/JPEG 的实际文件类型、尺寸和内容，不能只看扩展名。

## 导出约定

HTML 内嵌模型、样式和运行时。浏览器工具栏可下载 SVG；自动 SVG、PNG、JPEG 使用 `scripts/export.mjs`，后两者需要 Skill 内的 Playwright 和 Chromium。

所有静态图创建独立、全展开、无选择态且无动画的导出视图，保留标题、必要说明、条件与图例。当前缩放、平移、折叠或详情面板不影响导出范围；导出不能改变阅读器状态。编辑后自动导出以下载的修订 HTML 为输入。

位图默认 scale=2，可取 0.5–4。任一边超过 16,000 px 或总像素超过 40,000,000 时明确失败；降低 scale 或拆图，不裁切。JPEG 使用明确背景色。SVG 不接受 scale。

只能证明已做的检查：结构通过、浏览器就绪、截图审查、静态导出与实站/生产事实分别说明。浏览器不可用时可交付已校验 JSON 和已组装 HTML，但必须标明视觉、交互或导出未验证，不能偷偷换成另一种输出。
